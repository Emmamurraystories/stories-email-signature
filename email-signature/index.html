Install in Gmail

  1. Click Copy signature above.
  2. In Gmail, click the gear icon (top right) → See all settings.
  3. On the General tab, scroll to Signature → Create new → name it "Stories".
  4. Click inside the empty signature box and paste (Cmd+V / Ctrl+V).
  5. Under Signature defaults, select it for new emails (and replies if you like).
  6. Scroll to the bottom and click Save changes.
  7. Send yourself a test email and check the logo shows up.
